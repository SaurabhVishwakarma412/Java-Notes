# LeetCode Practice by Lesson

Each section has five problems chosen to exercise the ideas in its matching Java lesson. Try to solve each one before looking at an explanation, and write down the key data structure or pattern you used.

## 1. Strings

- [Valid Palindrome](https://leetcode.com/problems/valid-palindrome/) (Easy) - normalize and compare from both ends.
- [Reverse String](https://leetcode.com/problems/reverse-string/) (Easy) - mutate a character array with two pointers.
- [First Unique Character in a String](https://leetcode.com/problems/first-unique-character-in-a-string/) (Easy) - count characters and scan for the first unique one.
- [Longest Common Prefix](https://leetcode.com/problems/longest-common-prefix/) (Easy) - compare characters across multiple strings.
- [Valid Anagram](https://leetcode.com/problems/valid-anagram/) (Easy) - compare character frequencies.

## 2. Arrays

- [Contains Duplicate](https://leetcode.com/problems/contains-duplicate/) (Easy) - detect repeated values.
- [Product of Array Except Self](https://leetcode.com/problems/product-of-array-except-self/) (Medium) - combine prefix and suffix products.
- [Rotate Array](https://leetcode.com/problems/rotate-array/) (Medium) - rearrange values in place.
